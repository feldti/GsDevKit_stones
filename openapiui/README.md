# OpenAPI UI

This is the base software to visualize the OpenAPI specification of a project, 
developed and exported by PUM.

You should put the UI directory at (e.g.) /var/www/html/openapi/ui and put the "openapi.json" file of that specific product at the directory level of ui:

- /var/www/html/openapis/sm/v1/openapi.json
- /var/www/html/openapis/sm/v1/ui

You enter "https://computername/openapis/sm/v1/ui" at your browser and you get the API visualized
